❓ 使用帮助

🚀 快速开始

1. 添加节点：从左侧节点库拖拽节点到画布，或点击节点添加

2. 连接节点：拖拽节点的输出端口(右)到另一个节点的输入端口(左)

3. 配置属性：双击节点或选中后在右侧面板编辑属性

4. 执行生成：点击节点上的「生成」按钮，或顶部「一键执行」

5. 查看结果：生成完成后点击预览图查看大图


📋 标准工作流

📜 脚本生成器 → 🖼️ 分镜图生成器 → 🎬 视频生成器 → 📤 导出合成器

可选：👤 角色设计器（连接到分镜图生成器以保持角色一致性）

可选：🎵 音乐生成器（连接到导出合成器添加BGM）


⌨️ 快捷操作

• 拖拽空白处：移动画布

• 滚轮：缩放画布

• 双击节点：打开属性面板

• Delete键：删除选中节点

• 拖拽端口：创建连线

🔌 API 设置中心

🟡 检测本地代理…
🖥️ 代理服务地址（CORS 转发）
所有外部 API 请求都先转发到该地址的 Node 服务（server.js），以绕过浏览器 CORS 限制。
• 正常通过 http://localhost:3000 访问时留空即可；
• 直接双击打开本地 HTML（file://）时，默认使用 http://127.0.0.1:3000；
• 部署到云端时填写你的服务器域名，如 https://your-app.onrender.com。
🔥 豆包视频生成 API（火山引擎）
字节跳动火山引擎的视频/图片生成模型（Seedance / Seedream）。未配置 Key 时自动回退占位预览。
🌟 Toter 聚合网关
统一 AI 模型聚合网关（OpenAI 兼容），可调用聊天/文本类模型。⚠️ 实测该网关目前没有可用的视频生成端点：「入梦 Flash」实为文本聊天模型，调用其视频接口会返回服务端错误（invalid_api_platform）。如需视频，请用下方「自定义 API」接入你自己的视频网关。
🎛️ 本地 ComfyUI（Wan2.2 模型）
本地显卡运行 Wan2.2 开源视频模型（图生视频 / 文生视频 / 图文生视频），无需云端 API Key。
🧩 自定义 API（推荐：手动连接任意接口）★
这是最通用的「手动连接入口」：直接接入你自己的任意 OpenAI 兼容网关（图片 / 视频皆可）。填写接口地址、Key、模型名并选择类型，保存启用后它会出现在生成节点的模型下拉里。点「测试连接」可立即验证是否通。
